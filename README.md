# Dashboard Management

A minimal luxury dashboard for managing projects, built with React, TypeScript, and Tailwind CSS.

## Features

- **Minimal Luxury Design** - Clean, elegant UI with monochrome aesthetic
- **Project Management** - Track projects with status, dates, tech stack, and links
- **Edit Modal** - Click any card to edit project details
- **Filter & Search** - Filter by status or search by title/description
- **Dark/Light Mode** - Theme toggle with system preference support
- **Persistent Storage** - Projects saved to localStorage

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Radix UI (Dialog, Popover)
- React Day Picker (Calendar)
- Framer Motion (Hero animation)
- date-fns

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
